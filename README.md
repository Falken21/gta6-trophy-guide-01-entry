# GTA VI Trophy Guide & Tracker

[![GTA 6 Trophy Guide](https://make.fun/badge/gta6-trophy-guide-01.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Rank](https://make.fun/badge/gta6-trophy-guide-01/Falken21/gta6-trophy-guide-01-entry/rank.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Reward](https://make.fun/badge/gta6-trophy-guide-01/Falken21/gta6-trophy-guide-01-entry/reward.svg)](https://make.fun/bounty/gta6-trophy-guide-01)

Panduan dan tracker lengkap untuk 55 trofi PlayStation 5 Grand Theft Auto VI. Setiap trofi dilengkapi panduan langkah demi langkah beserta sumbernya, penanda missable, dan roadmap platinum. Checklist tersimpan otomatis di localStorage, dengan filter berdasarkan jenis dan grade, pencarian, mode spoiler yang menyembunyikan trofi cerita, serta ekspor/impor progres ke berkas JSON.

## Cara Pakai

Jalankan server statis dari root repo lalu buka `app/index.html`, misalnya:

```bash
npx serve .
```

Lalu buka `http://localhost:3000/app/index.html` di browser. Aplikasi berjalan sepenuhnya offline — tidak ada request jaringan saat dipakai.
